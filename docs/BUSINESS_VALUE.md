# 模拟业务场景评估

实际执行：`python scripts/business_benchmark.py`，结果见 `evaluation/upgrade/reports/business.json`。0名参与者、0次模型调用，明确是模拟场景诊断。

8个任务涉及搬迁试用、内部晋升、临时岗位奖金、离职期权、人才评估、离职系统权限及报酬保证条件。对比人工提供英文关键词后的加权词频搜索与既有B3保存结果，双方最多查看20块，检查能否覆盖全部已标注条件。

结果：辅助关键词 **7/8**，保存RAG排序 **7/8**。本轮不能证明RAG比关键词搜索更快或更准确；失败题与逐块顺序均保留。英文关键词为该基线提供了语言辅助，不能泛化为未经帮助的中文关键词搜索表现。

记录的“查看到第几张证据卡才覆盖全部条件”只是可复算代理，不是观察到的用户步骤。关键词CPU计算时间不与历史RAG结果的端到端耗时比较。用户任务时间、引用理解和满意度均记未测，不能写“真实企业验证”“效率提升百分比”。

当前产品的可演示价值是：统一中文问题入口、按账户保存与恢复、查看原文引用、明确反馈和知识库状态。价值是否转化为更高任务完成率，需要真实参与者在固定任务、相同资料和计时规则下进行后续交叉测试。
